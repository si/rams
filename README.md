# SuperRams - Derby County Fan Community

Welcome to the SuperRams website - a fan-first community for Derby County supporters.

## About

SuperRams has been part of the Derby County fan story for years – from matchday banter on Twitter to bringing thousands of Rams together online. Now we're evolving into something new.

This isn't the polished PR of the official club site. This is fan-first: real voices, raw reactions, and a community built on loyalty, history and pride.

## Features

- **Responsive Design**: Modern, mobile-friendly layout
- **Fan-First Content**: Real voices and raw reactions from the community
- **Social Integration**: Direct links to Bluesky, Facebook, and X (Twitter)
- **Community Focus**: Built for Rams fans everywhere

## Getting Started

1. Clone this repository
2. Open `index.html` in your web browser
3. The website is ready to use!
